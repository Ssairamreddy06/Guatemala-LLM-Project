# IMF Country Report Analysis – Guatemala (2025)

## Project Overview

This project presents an automated analysis of *IMF Country Report No. 25/260 – Guatemala (2025)* using lightweight Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), and financial data visualisation.

The pipeline extracts, summarises, validates, and visualises macroeconomic and financial stability information from an 85-page IMF report.

## Key Features

- *PDF Processing:* Text extraction, cleaning, token-aware chunking, and section summarisation.
- *Thematic Analysis:* Classification across seven financial stability themes.
- *Financial Indicators:* Structured JSON extraction with source validation and missing-value handling.
- *RAG Pipeline:* Local Sentence Transformers embeddings and FAISS vector search for evidence-grounded question answering.
- *Financial Dashboard:* Four-panel visualisation of economic trends, banking indicators, thematic distribution, and RAG performance.
